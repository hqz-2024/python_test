# PCM 音频播放器使用说明

## 🎵 功能介绍

这个程序可以：
- 📊 **读取 PCM 文件**并显示时域波形图
- 🎧 **播放音频**（点击播放按钮）
- ⏹️ **停止播放**（点击停止按钮）
- 📈 **显示音频统计信息**（最大幅度、RMS、时长等）

## 🚀 快速开始

### 1. 生成测试文件
```bash
python generate_test_pcm.py
```
这会生成 4 个测试 PCM 文件：
- `test_sine.pcm` - 440Hz 正弦波
- `test_mixed.pcm` - 混合频率波形  
- `test_sweep.pcm` - 扫频信号
- `test_pulse.pcm` - 脉冲信号

### 2. 运行播放器
```bash
python pcm_reader.py
```

### 3. 使用界面
- 程序会自动检测目录中的 PCM 文件
- 输入音频参数（采样率、声道数、位深度）
- 查看波形图
- 点击 **▶ 播放** 按钮播放音频
- 点击 **⏹ 停止** 按钮停止播放

### 按钮功能
- **▶ 播放**：播放当前加载的音频
- **⏹ 停止**：停止正在播放的音频
- **状态显示**：显示当前播放状态

### 信息面板
显示以下信息：
- **最大幅度**：音频的最大振幅值
- **RMS**：均方根值（音频响度指标）
- **时长**：音频总时长（秒）
- **采样率**：音频采样频率

## ⚙️ 支持的格式

### PCM 参数
- **位深度**：8位、16位、32位
- **采样率**：任意（常用：8000, 16000, 22050, 44100, 48000 Hz）
- **声道数**：1（单声道）、2（立体声）或更多

### 文件要求
- 文件扩展名：`.pcm`
- 格式：原始 PCM 数据（无文件头）
- 字节序：小端序（Little Endian）

## 🔧 使用技巧

### 1. 快速测试特定文件
修改 `pcm_reader.py` 中的 `quick_test()` 函数：
```python
def quick_test():
    filename = "your_audio.pcm"  # 你的文件名
    sample_rate = 44100          # 采样率
    channels = 1                 # 声道数
    bit_depth = 16              # 位深度
    
    # ... 其余代码
```

然后在文件末尾取消注释：
```python
if __name__ == "__main__":
    # main()  # 注释掉交互式运行
    quick_test()  # 启用快速测试
```

### 2. 处理大文件
- 程序会自动对显示数据进行下采样（最多显示 50,000 个点）
- 播放时使用原始完整数据
- 如果文件太大导致内存不足，可以修改 `max_points` 参数

### 3. 音频播放问题
如果播放有问题，检查：
- PCM 参数是否正确（采样率、位深度、声道数）
- 音频数据是否损坏
- 系统音频设备是否正常

## 📝 常见问题

### Q: 播放没有声音？
A: 检查以下几点：
1. PCM 参数设置是否正确
2. 系统音量是否打开
3. 音频文件是否包含有效数据
4. 尝试不同的采样率设置

### Q: 波形显示异常？
A: 可能原因：
1. 位深度设置错误
2. 声道数设置错误
3. 文件格式不是标准 PCM

### Q: 程序运行出错？
A: 确保已安装所需库：
```bash
pip install numpy matplotlib pygame
```

### Q: 如何处理立体声文件？
A: 程序会自动提取第一声道进行显示和播放。如需处理其他声道，可以修改代码中的声道处理逻辑。

## 🛠️ 自定义修改

### 修改播放音质
在 `play_audio()` 函数中修改：
```python
pygame.mixer.pre_init(
    frequency=current_sample_rate,  # 采样率
    size=-16,                       # 16位有符号
    channels=1,                     # 单声道
```
